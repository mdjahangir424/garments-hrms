# Garments HRMS — Flutter Web Prototype

This is the first Dashboard prototype. It uses sample data only; no real employee, attendance, payroll, or approval data is stored.

## Deploy with GitHub Actions

1. Upload these files to the root of a GitHub repository.
2. Ensure the default branch is named `main`.
3. Open **Settings → Pages** and set the source to **GitHub Actions**.
4. Open the **Actions** tab and run **Build and Deploy Flutter Web**, or push a commit.
5. After a successful deployment, open the Pages URL shown in the workflow.

## Important

- The default UI language is English.
- Dashboard navigation is a visual prototype; other modules are placeholders.
- Approve/Decline and Add Employee buttons show demo messages only.
- All numbers and names are sample data.
- The Dashboard layout should be compared with the approved reference PDF before further modules are built.
